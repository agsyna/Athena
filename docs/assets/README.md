# Assets

## `logo.png` and `logo-128.png`

Athena's mark: a lime owl on a dark rounded tile, in the same palette as the
app. The 512px file is used by the [root README](../../README.md) at an
explicit width; the 128px copy exists for the [recipe](../ai/RECIPE.md), which
renders as plain markdown where an image shows at its natural size.

The tile is deliberate here and deliberately absent from the extension icons in
[`extension/icons/`](../../extension/icons/). At README size the tile anchors
the mark against both a light and a dark GitHub theme. At 16px it went muddy and
swallowed the silhouette, so the toolbar icons are lime on transparent instead.

If you regenerate these, keep the eyes wide-set with a lime pupil inside each
dark socket. Solid dark eyes merge into a single bar the moment the image is
scaled down, and the owl stops reading as a face.

## Demos

Screen recordings are not kept in the repo. They live in a
[Drive folder](https://drive.google.com/drive/folders/1TiKVYXx3gvgkIWhWGJSrsC7nUsrvVWEy?usp=sharing)
linked from the README and the recipe, which keeps the repo small and means a
recording can be replaced without a commit.

Give each file a name that says which scenario it shows, since the folder is the
first thing a reviewer opens and a list of capture timestamps tells them
nothing.
